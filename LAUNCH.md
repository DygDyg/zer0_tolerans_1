# Zero Sector — Инструкция по запуску

## Исправленные проблемы

1. **Canvas не инициализировался** — canvas был скрыт через `display: none`, что могло вызывать проблемы с инициализацией. Теперь canvas всегда в layout (через `opacity`), а меню — абсолютные оверлеи поверх.

2. **Map не инициализировался** — `this.map` не устанавливался в конструкторе, что могло вызывать ошибки при первом рендере. Теперь инициализируется из `LEVELS[0]`.

3. **Обработка ошибок** — добавлены try-catch в игровой цикл и рендеринг для предотвращения крашей.

## Запуск игры

```bash
npm run dev
```

Откройте браузер по адресу `http://localhost:3000` (или другой порт, если 3000 занят).

## Как играть

### Главное меню
1. Нажмите **NEW CAMPAIGN** для начала новой игры
2. Выберите одного из 5 персонажей
3. Игра начнётся автоматически

### Управление
- **WASD** или **Стрелки** — движение
- **Мышь** — поворот камеры (требуется клик для захвата курсора)
- **Левая кнопка мыши** — стрельба
- **1-5** — выбор оружия
- **F/Q** — переключение оружия
- **ESC** — пауза

### Цель
- Уничтожить всех врагов на уровне
- Найти выход (зелёный маркер на радаре)
- Перейти на следующий уровень
- Пройти все 3 уровня для победы

### Особенности
- **5 персонажей** с разными характеристиками
- **5 видов оружия** с уникальными параметрами
- **Радар** показывает врагов (красные точки), предметы (жёлтые), выход (зелёный)
- **Система здоровья и брони** — броня поглощает 50% урона
- **Сохранение** — нажмите SAVE в меню паузы

## Структура уровней

1. **Docking Sector** — космическая станция, металлические коридоры
2. **Security Complex** — военный комплекс, больше врагов
3. **Bio Laboratory** — исследовательская лаборатория, мутанты

## Технические детали

- Разрешение: 320×224 (масштабируется до 640×448)
- Движок: собственный raycasting (DDA алгоритм)
- Рендеринг: Canvas 2D с процедурными текстурами
- Звук: Web Audio API (процедурная генерация)
- Сохранения: localStorage

## Известные ограничения

- Звуковая система инициализируется при первом клике (требование браузеров)
- Некоторые спрайты врагов могут быть простыми (процедурная генерация)
- Производительность зависит от браузера (целевой FPS: 60)

## Отладка

Если игра не запускается, проверьте консоль браузера (F12):
- Должно быть сообщение: "Game initialized successfully"
- Если есть ошибки, сообщите о них для исправления
